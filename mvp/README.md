# MVP 准入门

本目录目前有意不包含任何产品蓝图。Aurora 不允许用“MVP”绕过研究或儿童安全责任。

只有同时满足以下条件，产品蓝图才能进入本目录：

1. 已完成的研究报告明确了决策问题和证据。
2. 已接受的决策记录在包括“不做产品”在内的可信方案中选择了具体干预。
3. 可证伪假设、目标人群、成功阈值、时间范围和停止规则均已明确。
4. 已记录儿童安全、同意、数据最小化、家庭所有、删除和人工监督要求。
5. 测试不会收集超出必要范围的数据，也不会让更多儿童暴露于非必要风险。
6. 蓝图链接到对应报告、假设和决策记录。

最早的潜在准入点是 [RES-001](../research/RES-001-platform-gap.md) 完成之后，但 RES-001 完全可以得出“不应开发平台型 MVP”的结论。
