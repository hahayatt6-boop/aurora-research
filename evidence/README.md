## 可靠性标准

- **高：**与论点直接相关的透明一手数据或严谨研究，局限已知，并有实质性相互印证。
- **中：**可信但存在间接性、方法不完整、样本有限或冲突尚未解决。
- **低：**轶事、宣传材料、记录薄弱、高度间接或未经印证；只能启发假设，不能单独支撑重大结论。

可靠性针对具体论点判断。公司官网对产品功能可能是高可靠来源，对教育效果则可能是低可靠来源。
