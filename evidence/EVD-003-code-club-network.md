# 来源

- https://static.raspberrypi.org/files/about/Raspberry_Pi_Foundation_Annual_Review_2024.pdf

## 背景

发布者为 Raspberry Pi Foundation。公告日期为 2024-09-24；年报对应 2024 年。已核验标题、机构、日期或报告年度、项目数量和组织模式。

## 来源直接支持的陈述

基金会称 Code Club 于 2012 年创立，已覆盖逾两百万年轻人，并在 2024 年调整为可在学校、图书馆和 makerspace 运行的灵活模式。年报列出免费项目库、项目完成、徽章和 pathway 等聚合活动。

## 研究者解释

长期性可由免费内容、志愿者与场地网络、本地化和机构整合解释。路径与徽章提供有限连续性，但不等于统一、可迁移的长期成长档案。

## 可靠性

对组织历史、项目设计和聚合活动为高可靠；对同一参与者留存与学习因果为中低直接性。

## 局限与反证

聚合完成量不能证明同一学习者跨年参与，也不能证明徽章或路径导致组织长寿。
