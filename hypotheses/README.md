# 假设索引

假设必须可证伪并与决策相连。允许状态为 `proposed`、`testing`、`supported`、`weakened`、`rejected`、`inconclusive`。

| 编号 | 假设 | 状态 | 约束的决策 |
| --- | --- | --- | --- |
| [HYP-001](HYP-001-continuity-gap.md) | 缺少跨项目连续性限制了长期平台价值 | inconclusive | 是否继续验证连续性与平台假设 |
| [HYP-002](HYP-002-willingness-to-pay.md) | 核心目标家庭对儿童 AI/STEAM 产品的付费意愿足以支撑商业可行性 | weakened | 负面风险信号明确但不具独立性和代表性；待项目负责人决定停止、延期、转向或仓库外研究 |

使用[假设模板](../templates/hypothesis.md)创建记录。`supported` 只表示达到了预设阈值，不代表普遍真理。
