# 研究问题

中国 4-8 岁儿童家长对 "AI 引导人 + 创作工具" 的可接受价格区间是什么？该价格区间是否足以支持 Aurora 继续进入 MVP 准入门审查？

## 决策影响

本研究用于满足 ARV-003 条件 2 的严格解读：RES-003 必须包含中国市场的 WTP 实证数据，且不能仅依赖学术研究。若定价实验显示可接受价格低于可行单位经济，ADR-003 不得进入 MVP 准入门；若结果支持可行价格区间，RES-003 仍需结合 RES-003-EXP 的儿童验证结果再推进至 `review`。

## ARV-005 裁定回应

| ARV-005 要求 | 本研究如何回应 |
| --- | --- |
| 不能仅依赖学术论文中的行为意向 | 使用面向目标家长的定价实验，而非引用二手学术 WTP |
| 需要接近市场实践的方法 | 采用 Van Westendorp 价格敏感度测试，测量可接受价格区间和最优价格点 |
| 需量化意向-行为差距风险 | 增加价格锚定付费确定性题、替代支出题和需求量折减情景 |
| 不要求开发 MVP | 使用产品概念卡和价格实验，不收集儿童数据，不开发可用产品 |

## 范围与方法

- **人群**：中国 4-8 岁儿童家长或主要教育支出决策者
- **地区**：中国一线和新一线城市，至少覆盖 4 个城市层级样本来源
- **方法**：Van Westendorp 价格敏感度测试（PSM）+ 付费确定性校准 + 价值主张排序
- **样本量**：n >= 200，有效样本；若预算允许，目标 n = 300
- **场景**：纯软件订阅产品，核心价值为 AI 引导儿童完成故事/绘画/创作任务，并提供家长可见的成长报告
- **排除项**：不测试真实支付转化，不收集儿童姓名、照片、录音、精确位置、学校标识、联系方式或健康信息

## 为什么选择 Van Westendorp PSM

PSM 适合新产品早期定价，因为它不要求研究者预先指定唯一价格点。Aurora 当前没有已验证的产品形态，也没有真实购买漏斗；Gabor-Granger 或真实支付 A/B 测试需要更明确的价格锚点和可购买产品，现阶段会制造过强的产品假设。PSM 的局限是仍然属于陈述性偏好，因此本研究必须用价格锚定付费确定性和需求量折减情景降低高估风险。

## 产品概念卡

实验只展示文字和低保真图，不展示可操作原型，避免把概念偏好误读为产品体验验证。

**概念描述**：

Aurora 是一个早期产品概念，设想为面向 4-8 岁儿童的 AI 创作陪伴软件。孩子可以用语音和图画创作故事、角色和小作品。AI 的设计目标不是直接替孩子完成作品，而是通过问题帮助孩子开始、扩展和修改想法。家长界面设想提供每周创作摘要、兴趣变化提示和 AI 使用边界提醒。

**明确边界**：

- 不是学科提分课程
- 不是无限聊天机器人
- 不承诺替代老师或家长
- 不代表产品已经完成、效果已经验证或安全过滤可以完全避免所有风险
- 不保存可识别儿童身份的数据到研究仓库
- 需要家长同意和可见的使用报告

## 问卷结构

### 1. 筛选题

| 目标 | 题项 |
| --- | --- |
| 确认决策者 | 是否为 4-8 岁儿童的主要教育支出决策者 |
| 确认地区 | 城市层级与省份，仅保存聚合分类 |
| 确认教育支出背景 | 每月儿童课外教育/兴趣支出区间 |
| 排除无关样本 | 无 4-8 岁儿童或非主要决策者样本剔除 |

### 2. 价值主张理解检查

受访者阅读概念卡后回答 3 个理解题。任意 2 题错误则剔除，避免把不理解产品的人纳入定价估计。

| 检查点 | 正确理解 |
| --- | --- |
| AI 的角色 | 引导孩子思考，而非代写代画 |
| 家长界面 | 提供摘要和边界提醒 |
| 产品形态 | 软件订阅，不含硬件 |

### 3. PSM 四问

围绕"每月订阅价格"提问：

| PSM 问题 | 问法 |
| --- | --- |
| 太便宜 | 低到让你怀疑质量或安全，反而不太愿意使用的价格是多少？ |
| 便宜 | 你觉得划算、愿意尝试的价格是多少？ |
| 贵 | 你觉得偏贵，需要认真考虑的价格是多少？ |
| 太贵 | 贵到你不会购买的价格是多少？ |

价格输入使用区间选择而非自由填空，降低异常值：

`0-9`、`10-19`、`20-29`、`30-49`、`50-79`、`80-119`、`120-199`、`200-299`、`300+` 元/月。`300+` 按右删失处理，不指定任意中点或上界。

### 4. 付费确定性校准

| 指标 | 题项 | 用途 |
| --- | --- | --- |
| 概念兴趣 | 仅基于文字概念，且尚未真实试用或验证，你对这类产品的兴趣有多大？1-10 分 | 不作为购买确定性 |
| 价格锚定购买确定性 | 在 19/39/69 元/月三个真实支付价格下，分别测量未来 30 天购买可能性 | 只将对应价格下 8-10 分视为该价格的高确定性 |
| 替代支出 | 你会从哪类预算中支付？兴趣班/绘本/玩具/应用订阅/新增预算 | 判断是否挤占现有支出 |
| 续费预期 | 如果孩子每周使用 2 次，你愿意连续订阅多久？ | 区分首购与持续付费 |
| 家长信任门槛 | 哪些条件必须满足才会付费？ | 指导家长信任界面 |

### 5. 价值主张排序

受访者从以下价值中选出最重要的 3 项：

- 可能帮助孩子更愿意开始创作
- 可能支持孩子表达更多想法
- 家长期望替代一部分短视频/游戏时间
- 家长能看到使用摘要和阶段性报告
- AI 设计上不替孩子完成作品
- 数据安全和家长控制
- 每周有固定创作任务
- 可生成可分享的作品集

## 分析计划

### PSM 输出

| 输出 | 定义 | 决策用途 |
| --- | --- | --- |
| OPP | 最优价格点 | 初始订阅价格候选 |
| PMC | 边际便宜点 | 低价进入策略下限 |
| PME | 边际昂贵点 | 可接受价格上限 |
| 可接受价格区间 | PMC 至 PME | 判断是否覆盖单位经济 |

### 价格锚定校准与需求量折减

为回应 ARV-004 的意向-行为差距质疑，所有价格结论必须同时报告价格接受度和需求量折减，且不得把折减后的需求量误读为新的 PSM 价格点：

| 情景 | 计算方式 | 用途 |
| --- | --- | --- |
| 陈述偏好 | 全部有效样本 PSM | 价格接受度上限估计 |
| 价格锚定高确定性 | 分别使用 19/39/69 元购买确定性 8-10 分样本 PSM | 对应价格下的中性估计 |
| 需求量折减 | 对应价格高确定性样本比例 × 30% 转化率 | 只用于需求量/收入下限估计，不改变 PSM 价格点 |

不得只引用陈述偏好结果作为商业可行依据。

### 分层分析

至少按以下维度报告差异：

- 城市层级
- 儿童年龄段：4-5、6-8
- 家庭每月课外教育支出区间
- 是否已有儿童学习 App 订阅
- 家长对 AI 教育的信任水平

## 决策阈值

| 结果 | 对 RES-003 的影响 | 对 ADR-003 的影响 |
| --- | --- | --- |
| 目标价格下高确定性样本占比 >= 20%，且高确定性 PSM 覆盖预估最低可行月费 | 支持条件 2，可与 RES-003-EXP 一起进入 review 判断 | 可继续收窄，但不得声称已验证真实支付 |
| 高确定性 PSM 可行，但 30% 需求量折减后需求规模不足 | 条件 2 部分满足，需真实支付烟雾测试或降低成本结构 | 保持 active，不进入 MVP |
| 目标价格下高确定性样本占比 < 20% | 削弱 WTP 判断，EVD-029 的意向路径不能转化为近市场需求 | 重新评估家长价值主张 |
| 可接受价格低于最低可行月费 | 条件 2 不满足 | ADR-003 不应进入 MVP 准入门 |
| 付费必须依赖线下老师/机构背书 | 家庭直付模型削弱 | 需转向 B2B2C 或暂停消费级路径 |

**最低可行月费**须在数据分析前锁定，不得事后调整。若没有当前成本模型，先用三个阈值报告：19、39、69 元/月。

## 隐私与伦理

- 不招募儿童参与，不收集儿童个人材料
- 不收集家长姓名、手机号、邮箱、精确地址或可重新识别家庭的信息
- 城市只保存层级分类，不保存详细居住位置
- 原始问卷数据仓库外保存；仓库内只提交聚合统计、方法和结论
- 所有开放题引用必须去标识化，并且不得包含家庭、儿童或机构可识别线索

## 质量控制

| 风险 | 控制方法 |
| --- | --- |
| 概念理解不足 | 设置理解检查，失败样本剔除 |
| 价格异常值 | 使用价格区间选择，并检查 PSM 四问顺序一致性 |
| 社会期许偏差 | 不主动收集身份信息，强调没有正确答案 |
| 样本平台偏差 | 至少两个招募渠道，记录非识别渠道字段并报告渠道分布 |
| 高估购买意愿 | 使用 19/39/69 元价格锚定购买题和 30% 需求量折减 |
| 产品描述诱导 | 概念卡同时写明边界和非承诺事项 |

## 未知项

1. PSM 仍是陈述偏好，不能替代真实支付行为。
2. 产品概念卡无法体现真实 AI 引导体验，可能低估或高估价值感知。
3. 家长对安全和教育效果的信任可能强烈依赖品牌背书，早期 Aurora 无法直接复制。
4. 若目标价格低于 API 和运营成本，需先验证低成本模型或改为机构渠道。
