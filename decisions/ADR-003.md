# ADR-003: 采用"AI 引导人 + 创作工具"双轮驱动作为新方向

## 背景

RES-001 平台缺口研究和 RES-002 经济性研究均已完成，综合全部证据（EVD-001 至 EVD-023），原来的两条路径需要更新：

- **ADR-001**（暂缓连续性方向）：被接受为"不应以现有形态继续推进连续性"，但 ADR-003 补充了新方向——通过 AI 引导人（AI Guide）为创作工具提供连续性。
- **ADR-002**（停止/延期/转向）：被接受为"不应以纯软件订阅形态进入"，但 ADR-003 指出了差异化条件——AI 引导人 + 真人监督的混合模式。

## 证据摘要

| 证据 | 发现 | 对方向的启示 |
| --- | --- | --- |
| EVD-001 | 家庭偏好真人引导；现有 AI 家长控制工具少且差 | 需要真人或高可信 AI 引导，不能纯软件 |
| EVD-002 | 中国市场 AI 产品多但少有长期项目产品 | 市场有入口，缺连续性方案 |
| EVD-003 | MIT/Scratch 研究：长期项目需社区、导师、展示；缺连续性机制是主因 | 社区 + 导师 + 展示三要素是连续性的关键 |
| EVD-004 | 韩国研究：AI STEAM 对创造力正向，对批判思维无显著差异 | AI 可行，但需聚焦创造力 |
| EVD-005 | 可信度研究：人类 > AI；人类+AI > 人类 | AI 辅助成人监督可提升可信度 |
| EVD-006 | i+1 理论：略高于当前水平的挑战最有效 | 创作工具需适配儿童当前能力 |
| EVD-007 | Meta 分析：技术增强对 STEAM 学习有正向中等效应 | 技术方向整体可行 |
| EVD-008 | 元认知研究：引导式反思比自由反思更有效 | AI 引导人需结构化反思提示 |
| EVD-009 | AI 素养研究：家庭视角有用但有限；学校需专门课程 | 家庭产品不能替代学校教育 |
| EVD-010 | AI 素养框架：伦理、安全、偏见、隐私、透明度、问责 | AI 引导人需覆盖这些维度 |
| EVD-011 | Kano 分析：基础功能（隐私、安全）是必备；AI 创作是兴奋功能 | 隐私安全是门槛，AI 创作是差异化 |
| EVD-012 | 竞品：13 款产品，多为课程或工具，少有长期平台 | 缺长期项目平台，有机会 |
| EVD-013 | 中国 Kano：隐私安全是必备；AI 创作是兴奋功能 | 与 EVD-011 一致，隐私安全是门槛 |

| EVD-015 | 竞品定价：¥20-500/月，高端 ¥300+ | ¥100-200/月可行 |
| EVD-016 | 定价心理学：锚定、捆绑、分层 | 需分层定价策略 |
| EVD-017 | 可负担性：需平衡 WTP 与可及性 | ¥80-120/月是甜蜜点 |
| EVD-018 | LLM 从游戏行为识别发展能力 | AI 可从创作行为推断能力 |
| EVD-019 | 肯尼亚 DCE：家长愿为 AI+真人监督付费 | AI+真人监督模式可行 |
| EVD-020 | iHuman 财报：收入下降但仍盈利 | AI 教育订阅可盈利但增长难 |

| EVD-023 | Frontiers WTP 研究：中国家长愿为 AI 教育付费 | 付费意愿存在 |

## 决策

**采用"AI 引导人 + 创作工具"双轮驱动作为新方向**，具体为：

1. **AI 引导人**：基于 LLM，为儿童提供创作引导、反思提示、能力识别，覆盖 EVD-010 的 AI 素养维度。
2. **创作工具**：儿童进行故事、游戏、艺术创作的工具，提供 i+1 适配挑战（EVD-006）。
3. **真人监督层**：家长或教师可通过仪表盘查看 AI 引导内容，必要时干预（EVD-005, EVD-019）。
4. **定价 ¥80-150/月**：基于 EVD-014, EVD-015, EVD-017。
5. **隐私安全是门槛**：基于 EVD-011, EVD-013，必须在 MVP 阶段就实现。

## 被替代的决策

- **ADR-001**（暂缓连续性方向）：被 ADR-003 替代。ADR-001 的核心判断（不应以现有形态推进连续性）仍然有效，但 ADR-003 提供了新方向——通过 AI 引导人为创作工具提供连续性。
- **ADR-002**（停止/延期/转向）：被 ADR-003 替代。ADR-002 的核心判断（不应以纯软件订阅进入）仍然有效，但 ADR-003 指出了差异化条件——AI 引导人 + 真人监督的混合模式。
