# Aurora 研究宪章

## 使命

判断 AI 是否以及如何在不损害儿童福祉与自主性的前提下，帮助儿童发展创造力、思维能力、项目能力、主体性和终身学习能力。

## 核心问题

儿童创造力教育是否是一个值得未来十年持续投入的机会？什么证据足以支持某一种干预方式？

## 原则

1. 研究先于产品选择。
2. 只有可能改变决策的研究才值得优先投入。
3. 事实、解释和建议必须清晰分开。
4. 反证是必需产出，不是需要回避的麻烦。
5. 长期学习价值高于新奇感和短期活跃度。
6. 儿童不是流量、数据来源或方便的测试对象。
7. 家庭拥有未来可能产生的长期成长数据。
8. 继续、转向、收窄或停止都是合法结论。

## 研究范围

Aurora 研究儿童发展、创造力与项目式学习、家庭和教育者需求、AI 的合理角色、现有产品生态、学习连续性与成长档案、信任与隐私、分发方式及可持续商业模式。

## 边界

Aurora 不在 Git 中收集可识别儿童身份的数据，不在缺乏证据时宣称教育效果，不以依赖性或强迫性使用为目标，也不把技术能力直接等同于学习价值。

## 决策标准

重大建议必须列明支持证据、反证、置信度、未解决问题、可逆性和复审触发条件。证据不足时，正确的决定是暂缓，并明确缺少什么证据。

## 停止条件

当可信证据表明长期价值很弱、儿童安全风险不成比例、无法建立可信的同意与家庭控制机制，或商业模式必须依赖损害儿童利益的激励时，应停止或显著收窄该方向。
